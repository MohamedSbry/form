# Contact Form Project
## 📌 Description
A simple and responsive Contact Form web application that allows users to submit their information and store it in a MySQL database using PHP and Fetch API.

---
## 🚀 Features
- Responsive design (Mobile / Tablet / Desktop)
- Clean and modern UI
- Form validation (required fields)
- Fetch API (no page reload)
- PHP backend for handling requests
- MySQL database integration
- Easy to edit and customize

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript 
- PHP
- MySQL

---

## 📁 Project Structure
index.html → Frontend page  
style.css → Styling file  
script.js → JavaScript (Fetch API)  
insert.php → Backend (PHP API)  
database.sql → Database structure  

---

## ⚙️ How to Run

1. Install XAMPP  
   https://www.apachefriends.org/

2. Move project folder to:
   C:\xampp\htdocs\contact-form

3. Start Apache & MySQL

4. Open phpMyAdmin:
   http://localhost/phpmyadmin

5. Create database:
   form_db

6. Import database.sql

7. Run project:
   http://localhost/contact-form

---

## 📌 Note
- Do NOT open index.html directly
- Always run via localhost
- Make sure Apache & MySQL are running
