========================================
        FORM PROJECT
========================================

 Project Description:
This is a simple and professional Contact Form web application.
It allows users to submit their information which is stored in a MySQL database using PHP backend and Fetch API.

========================================
Features:
========================================
- Responsive design (Mobile / Tablet / Desktop)
- Clean and modern UI
- Form validation (required fields)
- Fetch API (No page reload)
- PHP backend for data handling
- MySQL database integration
- Secure and simple structure
- Easy to customize and extend

========================================
🛠 Technologies Used:
========================================
- HTML5
- CSS3
- JavaScript 
- PHP
- MySQL

========================================
📁 Project Files:
========================================
/index.html      → Main frontend page
/style.css       → Styling file
/script.js       → JavaScript logic (Fetch API)
/insert.php      → Backend API (PHP)
/database.sql    → Database structure

========================================
⚙️ Installation Steps:
========================================

1- Install XAMPP
   https://www.apachefriends.org/

2- Move project folder to:
   C:\xampp\htdocs\form

3- Start Apache and MySQL from XAMPP Control Panel

4- Open phpMyAdmin:
   http://localhost/phpmyadmin

5- Create database:
   form_db

6- Import database.sql file

7- Open project in browser:
   http://localhost/form

========================================
📌 Notes:
========================================
- Make sure Apache and MySQL are running before opening the project.
- Do not open index.html directly; always use localhost.
- Database name must be: form_db
